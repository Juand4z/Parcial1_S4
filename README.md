## Compilación y ejecución

Todos los comandos se ejecutan dentro de la carpeta del proyecto.

Compilar los módulos de apoyo:

```
elixirc .\datos.exs .\liquidacion.exs .\reportes.exs .\util.ex .\validaciones.exs
```

Ejecutar el programa:

```
elixir .\programa.exs
```

Ejecutar mediciones:

```
elixir .\mediciones.exs 
```
